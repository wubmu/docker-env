## 1. 目标
创建 JavaScript 和 Python 两个版本的 JSON 到 Markdown 转换脚本，将认证成功率分析的 JSON 结果转换为易于阅读的 Markdown 报告，支持执行摘要风格，帮助运维人员快速分析问题和决策系统健康状况。

## 2. 实施
- [ ] 2.1 创建 `n8n/n8n-script/json-to-markdown.js`，实现 JavaScript 版本的转换脚本，包含以下功能：
  - 从 n8n 节点接收 JSON 输入
  - 计算告警级别（正常≥90%，警告70-90%，严重<70%）
  - 生成执行摘要风格的 Markdown 报告，包含：
    - 报告标题和时间戳
    - 关键指标卡片（总体成功率、总尝试次数、成功/失败次数、告警级别徽章）
    - 问题租户列表（按成功率从低到高排序，显示租户 ID 和名称）
    - 详细失败记录表格（时间戳、租户、用户、认证方式、失败原因）
    - 按认证方式分组的统计表格（认证方式、成功率、总次数、失败原因统计）
    - 按租户分组的详细统计（租户 ID、名称、总体成功率、各认证方式统计）
  - 使用 Markdown 视觉元素（徽章、表格、进度条等）
  - 返回 Markdown 字符串

- [ ] 2.2 创建 `n8n/n8n-script/json-to-markdown.py`，实现 Python 版本的转换脚本，功能与 JavaScript 版本一致：
  - 从标准输入读取 JSON 数据
  - 执行相同的转换逻辑
  - 输出 Markdown 到标准输出

- [ ] 2.3 更新 `n8n/n8n-script/认证成功率低告警分析.md` 文档，添加：
  - 转换脚本功能说明
  - 告警级别定义说明
  - Markdown 报告示例
  - 在 n8n 中使用转换脚本的配置示例
  - 不同输出场景（邮件、IM、文件）的使用建议
