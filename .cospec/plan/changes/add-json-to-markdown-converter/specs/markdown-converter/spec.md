## ADDED Requirements

### Requirement: JSON 到 Markdown 转换
系统 SHALL 能够将认证成功率分析的 JSON 结果转换为易于阅读的 Markdown 报告，支持执行摘要风格，帮助运维人员快速分析问题和决策系统健康状况。

#### Scenario: 生成执行摘要风格报告
- **WHEN** 系统接收到认证分析的 JSON 结果
- **THEN** 系统生成包含以下内容的 Markdown 报告：
  - 报告标题和生成时间
  - 顶部关键指标卡片区域（突出显示重要信息）
  - 问题租户列表（按优先级排序）
  - 详细的数据表格

#### Scenario: 告警级别自动标识
- **WHEN** 系统计算总体或租户的成功率
- **THEN** 系统根据以下阈值自动标识告警级别：
  - 严重（🔴）：成功率 < 70%
  - 警告（🟡）：70% ≤ 成功率 < 90%
  - 正常（🟢）：成功率 ≥ 90%
- **AND** 在报告中使用相应的徽章和颜色标识

#### Scenario: 显示关键指标
- **WHEN** 生成 Markdown 报告
- **THEN** 系统在顶部突出显示以下关键指标：
  - 总体成功率（百分比 + 告警徽章）
  - 总尝试次数
  - 成功次数
  - 失败次数
  - 成功率可视化进度条

#### Scenario: 问题租户优先级排序
- **WHEN** 存在多个租户且部分租户成功率较低
- **THEN** 系统按成功率从低到高排序展示问题租户列表
- **AND** 显示租户 ID、名称（如果有）、成功率、尝试次数

#### Scenario: 详细失败记录表格
- **WHEN** 生成 Markdown 报告
- **THEN** 系统以表格形式展示所有失败记录，包含以下列：
  - 时间戳（转换为易读格式）
  - 租户 ID
  - 用户名称
  - 认证方式
  - 失败原因

#### Scenario: 认证方式统计表格
- **WHEN** 生成 Markdown 报告
- **THEN** 系统按认证方式分组统计并展示表格，包含：
  - 认证方式
  - 成功率（百分比 + 告警徽章）
  - 总尝试次数
  - 成功次数
  - 失败次数
  - 失败原因及次数统计

#### Scenario: 租户详细统计
- **WHEN** 生成 Markdown 报告
- **THEN** 系统按租户分组展示详细统计，包含：
  - 租户 ID
  - 租户名称（如果有）
  - 总体成功率（百分比 + 告警徽章）
  - 该租户下各认证方式的统计信息

#### Scenario: 使用视觉元素增强可读性
- **WHEN** 生成 Markdown 报告
- **THEN** 系统使用以下视觉元素：
  - Markdown 表格展示结构化数据
  - 徽章（badge）标识告警级别和状态
  - 进度条可视化成功率
  - 分隔线和标题层次结构

#### Scenario: 支持多种输出场景
- **WHEN** Markdown 报告用于不同场景（邮件、IM、文件）
- **THEN** 报告格式兼容多种 Markdown 渲染器
- **AND** 支持在邮件客户端、Slack/钉钉、GitHub 等平台正常显示

#### Scenario: JavaScript 脚本执行
- **WHEN** 在 n8n 中使用 JavaScript 运行器执行 `json-to-markdown.js`
- **THEN** 脚本从输入参数 `input` 中获取 JSON 数据
- **AND** 返回 Markdown 字符串

#### Scenario: Python 脚本执行
- **WHEN** 在 n8n 中使用 Python 运行器执行 `json-to-markdown.py`
- **THEN** 脚本从标准输入读取 JSON 数据
- **AND** 输出 Markdown 到标准输出

#### Scenario: 处理空数据或无失败记录
- **WHEN** 输入 JSON 中没有失败记录或数据为空
- **THEN** 系统生成包含适当信息的报告
- **AND** 在相关表格中显示"无记录"等提示信息

#### Scenario: 时间戳格式化
- **WHEN** 显示时间戳信息
- **THEN** 系统将 ISO 格式时间戳转换为易读的本地时间格式（如：2026-01-14 14:31:07）
