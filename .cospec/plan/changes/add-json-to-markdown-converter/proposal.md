# 变更：添加 JSON 到 Markdown 转换脚本

## 原因
认证成功率分析脚本生成的 JSON 结果虽然结构化，但不利于运维人员快速阅读和决策。需要将 JSON 结果转换为易于阅读的 Markdown 格式，以便在邮件通知、IM 消息或文件报告中使用，帮助运维人员快速识别问题并做出决策。

## 变更内容
- 添加 JavaScript 版本的 JSON 到 Markdown 转换脚本
- 添加 Python 版本的 JSON 到 Markdown 转换脚本
- 转换脚本支持执行摘要风格的报告，包含：
  - 顶部关键指标概览（总体成功率、失败次数、告警级别）
  - 告警级别自动标识（根据成功率阈值：正常≥90%，警告70-90%，严重<70%）
  - 按优先级排序的问题租户列表
  - 详细的失败记录表格
  - 按认证方式分组的统计表格
  - 按租户分组的详细统计（包含租户 ID 和关联的名称信息）
  - 优化后的视觉元素（徽章、进度条等）
- 转换后的 Markdown 适用于多种用途（邮件、Slack/钉钉 IM、文件报告等）
