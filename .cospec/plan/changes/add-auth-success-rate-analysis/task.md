## 1. 目标
创建 JavaScript 和 Python 两个版本的认证成功率分析脚本，用于在 n8n 中分析认证数据，提供详细的统计信息。

## 2. 实施
- [ ] 2.1 创建 `n8n/n8n-script/auth-success-rate-analysis.js`，实现 JavaScript 版本的认证分析脚本，包含以下功能：
  - 从输入数组中提取认证失败记录
  - 计算总体成功率（成功次数/总次数）
  - 按认证方式（login_type）分组统计成功率和次数
  - 按认证方式统计失败原因及次数
  - 按租户（tid）分组统计成功率和各认证方式的统计
  - 返回结构化的 JSON 对象
  
- [ ] 2.2 创建 `n8n/n8n-script/auth-success-rate-analysis.py`，实现 Python 版本的认证分析脚本，功能与 JavaScript 版本一致：
  - 从输入数组中提取认证失败记录
  - 计算总体成功率
  - 按认证方式分组统计
  - 按租户分组统计
  - 返回结构化的 JSON 对象

  - 输入数据格式说明
  - 输出数据结构说明
  - 在 n8n 中使用该脚本的配置示例
