# 变更：添加认证成功率分析脚本

## 原因
当前 n8n 运维告警系统中缺少对认证数据的统计分析功能，需要能够分析认证成功率、失败原因、各认证方式的统计信息，以及按租户维度的分析。

## 变更内容
- 添加 JavaScript 版本的认证成功率分析脚本
- 添加 Python 版本的认证成功率分析脚本
- 脚本支持从 n8n 节点接收 JSON 数组输入
- 输出结构化的 JSON 数据，便于 n8n 后续处理
- 统计内容包括：
  1. 认证失败的详细信息列表
  2. 总体成功率及统计
  3. 各认证方式（login_type）的成功率、次数及失败原因统计
  4. 每个租户（tid）的总成功率及各认证方式的统计

## 影响
- **受影响的规范**：认证分析功能
- **受影响的代码**：
  - `n8n/n8n-script/`：新增 `auth-success-rate-analysis.js` 和 `auth-success-rate-analysis.py` 两个脚本文件
  - `n8n/n8n-script/认证成功率低告警分析.md`：更新文档，添加使用说明和示例
